# Accessibility Audit Report

## Website
Maharishi Arvind College

## Audit Tool
Google Chrome Lighthouse

## Accessibility Score
92/100

## Issue 1: Insufficient Color Contrast

### Evidence
Lighthouse reported:
"Background and foreground colors do not have a sufficient contrast ratio."

### Priority
Medium

### Remediation
Improve the contrast between text/icon colors and their background so that content is easier to read for users with low vision.

## Accessibility Checks Passed

- Form elements have associated labels
- Buttons have accessible names
- Document has a main landmark
- Heading elements appear in sequential order
- HTML element has a valid language attribute
- Links have discernible names
- Touch targets have sufficient size and spacing

## Manual Accessibility Checks

The following areas should also be checked manually:

- Keyboard focus
